# Isolated native Android architecture evidence

Disposable Step-4.2 harness. **Not STORE production source.** Synthetic data only,
package `test.store.spike`; its exported debug command activity is intentionally
not a production authorization pattern. No STORE profile, DB or runtime access.

## Reproduction

JDK 21, Gradle 8.13, AGP 8.13.2, Kotlin 2.2.21; Android API 36 x86_64.
Room 2.8.5, BundledSQLiteDriver 2.7.1, PDFBox-Android 2.0.27.0.
All SDK/Gradle/AVD caches remain ignored inside this directory. Set JAVA_HOME,
ANDROID_HOME, ANDROID_USER_HOME, ANDROID_AVD_HOME and GRADLE_USER_HOME accordingly.

On this Windows host an ASCII alias was needed for the emulator. With an unused
drive letter, `subst V: <absolute-native-validation-directory>` maps the same
isolated files; set Android paths to `V:\.tools\sdk`, `V:\.android-home`,
`V:\.android-home\avd`. The local AVD INI points to that alias. Remove the alias
with `subst V: /D` only after stopping the emulator. The validation run removed
its alias and stopped its AVD; recreate the alias before reusing that local AVD.

1. `gradle :app:assembleDebug --no-daemon --console=plain`
2. Boot the isolated API-36 AVD; verify `adb shell getprop sys.boot_completed` is 1.
3. `adb install -r app/build/outputs/apk/debug/app-debug.apk`
4. `python run_native.py` (optional `SPIKE_SERIAL`, default emulator-5554).
5. Inspect `out/native-results.json`; render/inspect both pulled PDF pages separately.

The runner uses `adb shell am force-stop test.store.spike`, verifies its PID is
gone, then starts a fresh process. It never kills STORE. Seven exception cases
and seven externally killed paused cases each require three successful restarts.
Expected states: points 1–5 OLD, 6–7 NEW. Both DB and media are published through
one AtomicFile pointer; points 5/6 are its two sides, not independent renames.
Inactive generations are retained, not garbage-collected.

PDFs use Android PdfDocument for visible rendering and PDFBox only for Subject
metadata transport. No OCR, browser, Electron or DB mutation. The synthetic asset
was generated by the preceding host fixture, not copied from personal data.
V1 is untrusted and unauthenticated: validation rejects malformed data but cannot
detect an otherwise valid edited price. Step-2 does not require export provenance
authentication. Any eventual import still requires domain authorization and full
validation before persistence.

PDFBox candidate: Apache-2.0, API 19+ according to its
[maintainer](https://github.com/TomRoush/PdfBox-Android). This spike is not a general
parser security certification, device matrix, release-minification test, or
power-loss durability certification. Build success alone is not native PASS.
